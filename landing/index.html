Core Features

Everything an agent needs

01

Tools

Typed input schemas, validation before execution, per-tool retries and timeouts. Errors feed back to the model.

guide/tools
02

Memory

In-memory or file-based sessions out of the box. Implement IMemoryAdapter to connect any database.

guide/memory
03

Guardrails

Input, output, and tool-level safety checks. Block, modify, or pass through at every layer.

guide/guardrails
04

Handoffs

Delegate tasks between specialized agents. Context transfers cleanly. Loop detection is automatic.

guide/handoffs
05

Tracing

Full run traces with step timing, token usage, tool calls, handoffs, and errors. One method after run().

guide/tracing
06

Providers

OpenAI built in. Swap to Gemini, Claude, or Groq by implementing a 2-method interface.

guide/providers
Quick Start

Running in under a minute

Install, set a key, define tools, build the agent. The loop, dispatch, and tracing are handled.

Full Guide npm 
import { Agent, OpenAIProvider } from "mitm-ai";

const agent = Agent.builder()
  .setName("myAgent")
  .setProvider(new OpenAIProvider())
  .setInstructions("You are helpful.")
  .tool(myTool)
  .setMemory(new FileAdapter(), "user-1")
  .addInputGuardrail(safetyCheck)
  .setTimeout(30_000)
  .build();

agent.on("step", (e) => console.log(e.step));

const result = await agent.run("Build hello.py");
const trace  = agent.getLastTrace();
// trace.durationMs  trace.tokenUsage
